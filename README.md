# 🏥 Hospital Management System (MEDICARE)

A robust, **full-stack healthcare management system** designed to streamline patient care, appointment scheduling, and hospital administration.

## 🎯 Project Goal
The core objective of the **Hospital Management System** is to digitize healthcare workflows. It provides a seamless interface for patients to manage their health journey while giving administrators powerful tools to oversee hospital operations and staff.

## 🏗️ Project Structure
The repository is organized into three main modules to ensure a clean separation of concerns:

* **`frontend/`** (Patient Portal)
    * Built with **React** and **Vite**.
    * Handles user registration, appointment booking, and service browsing.
* **`backend/`** (Core API)
    * Powered by **Node.js** and **Express**.
    * Manages server-side logic, database interactions, and secure API endpoints.
* **`admin/`** (Management Panel)
    * A dedicated React-based dashboard for hospital staff.
    * Used for managing doctor schedules and verifying appointments.

## ✨ Key Functionalities
* **User Management:** Secure signup/login for patients.
* **Appointment System:** Real-time scheduling and status tracking.
* **Healthcare Services:** Categorized listings of medical departments and specialists.
* **Admin Oversight:** Centralized control over hospital data and staff records.

## 🛠️ Tech Stack
* **Frontend:** React, Vite, Tailwind CSS
* **Backend:** Node.js, Express
* **Database:** MongoDB
* **Authentication:** Clerk (Complete User Management & Auth)
